## Findings logged while measuring

- `run_text_llm` mis-parsed streamed code fences split across chunks;
  fixed in Phase 0 (commit "fix: parse streamed code fences independently
  of chunk boundaries").
- `INTERPRETER_INSECURE_ROUTES=true` needs `python-multipart`, never
  declared; added in Task 8.
- `Terminal.stop()` halts running code but leaves Jupyter kernels alive;
  only `terminate()` kills them, and nothing calls it at process exit, so
  kernels outlive the interpreter. Phase 2 item.
- `default_system_message.py` sends the host's IP to ip-api.com on every
  import and puts the result in the prompt prefix. Task 11 makes it lazy;
  Phase 3 moves dynamic text out of the cached prefix.
